# Instructions for migrating a protocol from PDF to Markdown

These steps will convert a legacy protocol provided in PDF format into a markdown, `README.md` in the root of this repository.

## Legacy protocol input

1. Upload your old protocol PDF here as `source.pdf`
2. Go to the **Actions** tab
3. Run **Prepare migration from PDF**
4. Open the repo in GitHub web editor / VS Code with Copilot
5. Ask Copilot to migrate `legacy/source.txt` into `README.md`
6. Open a pull request
